# Line Bridge

Dragging a conveyor, duct or conduit line across queued build plans no longer cuts them: the line goes over planned blocks and construction sites with bridges and junctions, the same as over built ones.

![Line Bridge](https://raw.githubusercontent.com/m3rcur1e/line-bridge/media/line-bridge.webp)

Bridge and power node chains step around planned blocks too, so no node lands on a plan and gets dropped.

![Line Bridge with power nodes](https://raw.githubusercontent.com/m3rcur1e/line-bridge/media/line-bridge-nodes.webp)

### Customizable

In **Settings › Line Bridge** (or **Cur1e Mods**):

- bridging over build plans on/off
